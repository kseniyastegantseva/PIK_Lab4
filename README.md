# Лабораторная работа № 4

Пример использует порождающий шаблон «Фабричный метод». Классы `TeaMaker` и `CoffeeMaker` создают свои напитки в методе `create_drink`. Общий метод `make_drink` готовит созданный напиток.

## Запуск

Нужен Python 3. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
```

Активируйте окружение: в Linux — `source .venv/bin/activate`, в Windows PowerShell — `.venv\Scripts\Activate.ps1`.

```bash
python -m pip install -r requirements.txt
python main.py
```

Введите `1` для чая или `2` для кофе. При другом вводе появится сообщение об ошибке.

## Тестирование

```bash
python -m pytest -v
python -m behave
```

`pytest` — фреймворк для модульных тестов, который можно применять при TDD. В тесте `test_make_drink_calls_prepare` используется `Mock`: он заменяет напиток и проверяет вызов его метода. `behave` выполняет BDD-сценарии из файла `features/drinks.feature`.

TDD — это порядок работы: сначала написать тест, убедиться, что он не проходит, затем написать код и снова запустить тест. Наличие тестов само по себе не подтверждает, что разработка велась таким способом.
