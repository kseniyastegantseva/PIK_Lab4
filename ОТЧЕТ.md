## Задание

Реализовать шаблон проектирования для произвольной предметной области. Применить в тестах TDD-фреймворк, BDD-фреймворк и Mock-объекты. Для минимального варианта достаточно одного шаблона.

## Решение

Предметная область — приготовление напитков. Применён порождающий шаблон «Фабричный метод»: классы `TeaMaker` и `CoffeeMaker` по-своему реализуют метод `create_drink` и создают чай или кофе. Общий метод `make_drink` вызывает метод приготовления созданного напитка.

Для модульных тестов используется `pytest`, для BDD-сценариев — `behave`. В одном из тестов `Mock` заменяет напиток и позволяет проверить, что его метод `prepare` вызван.

## Текст программы

### drinks.py

```python
class Tea:
    def prepare(self):
        return "Чай готов"


class Coffee:
    def prepare(self):
        return "Кофе готов"


class DrinkMaker:
    def create_drink(self):
        raise NotImplementedError

    def make_drink(self):
        drink = self.create_drink()
        return drink.prepare()


class TeaMaker(DrinkMaker):
    def create_drink(self):
        return Tea()


class CoffeeMaker(DrinkMaker):
    def create_drink(self):
        return Coffee()
```

### main.py

```python
from drinks import CoffeeMaker, TeaMaker


def main():
    print("1 — чай")
    print("2 — кофе")
    choice = input("Выберите напиток: ")

    if choice == "1":
        maker = TeaMaker()
    elif choice == "2":
        maker = CoffeeMaker()
    else:
        print("Такого напитка нет")
        return

    print(maker.make_drink())


if __name__ == "__main__":
    main()
```

### test_drinks.py

```python
from unittest.mock import Mock

from drinks import Coffee, CoffeeMaker, Tea, TeaMaker


def test_tea_maker_creates_tea():
    assert isinstance(TeaMaker().create_drink(), Tea)
    assert TeaMaker().make_drink() == "Чай готов"


def test_coffee_maker_creates_coffee():
    assert isinstance(CoffeeMaker().create_drink(), Coffee)
    assert CoffeeMaker().make_drink() == "Кофе готов"


def test_make_drink_calls_prepare():
    drink = Mock()
    drink.prepare.return_value = "Напиток готов"
    maker = TeaMaker()
    maker.create_drink = Mock(return_value=drink)

    assert maker.make_drink() == "Напиток готов"
    maker.create_drink.assert_called_once_with()
    drink.prepare.assert_called_once_with()
```

### features/drinks.feature

```gherkin
# language: ru
Функция: Приготовление напитков
  Сценарий: Приготовление чая
    Допустим выбран чай
    Когда напиток приготовлен
    Тогда результат должен быть "Чай готов"

  Сценарий: Приготовление кофе
    Допустим выбран кофе
    Когда напиток приготовлен
    Тогда результат должен быть "Кофе готов"
```

### features/steps/drink_steps.py

```python
from behave import given, when, then

from drinks import CoffeeMaker, TeaMaker


@given("выбран чай")
def choose_tea(context):
    context.maker = TeaMaker()


@given("выбран кофе")
def choose_coffee(context):
    context.maker = CoffeeMaker()


@when("напиток приготовлен")
def make_drink(context):
    context.result = context.maker.make_drink()


@then('результат должен быть "{expected}"')
def check_result(context, expected):
    assert context.result == expected
```
